# OIR-loader
Function to load .oir files as numpy arrays. 

* Download the oracle 21 python development kit (Note: Eclipse Temurin 25 does not work as the development kit, mmust oet oracle zijn!!!)
* Download visual studio and install MSVC v143 - VS 2022 C++ x64/x86 build tools (maybe also need Windows 10 SDK also when using windows 11) 
* Python 3.13 does not work, 3.11 does work.\
\
See example file for example usage\
\
Install using: pip install git+https://github.com/ArnonBAB/OIR_loader
